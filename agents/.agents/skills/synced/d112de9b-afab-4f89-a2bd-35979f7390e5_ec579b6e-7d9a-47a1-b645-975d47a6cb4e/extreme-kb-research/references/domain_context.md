# Extreme Networks Domain Context (background reference)

This is orientation material only. Always re-verify specifics against the Extreme Networks
Knowledge Base (via `Extreme_Knowledgebase_Query`) and cite fresh sources per response —
this file is not a citable source itself.

## CUID (Customer Unique Identifier)

- Represents a customer's license pool.
- Must match between Extreme Portal and ExtremeCloud IQ for correct entitlement display.
- Used for partner account linking via Welcome Letters.

## Platform ONE vs. XIQ

- Extreme Platform ONE is a superset of ExtremeCloud IQ (XIQ).
- Adds security capabilities (Universal ZTNA, Cloud PKI, NAC), AI capabilities, and
  third-party device management (TPME - Third-Party Management Engine).
- Backward-compatible with XIQ — no rip-and-replace migration required.
- Key Platform ONE capabilities: Third-Party Management Engine (TPME), Universal ZTNA,
  Cloud PKI, Certificate Lifecycle Management, Guest Wi-Fi, WIPS, Real-Time Location
  Tracking, Conversational and Agentic AI, AI Expert interface, Composable Workspace,
  Zero-Touch Fabric, Enterprise Agreement licensing.

## K-12 Education Solution Pattern

- Wireless: AP4000 (Wi-Fi 6E)
- Switching: 4000 / 5420 / 5520 Series in a core/distribution/edge architecture
- Cloud management: Platform ONE or XIQ
- Key buying consideration: E-Rate eligibility

## Stadium / Large Venue Solution Pattern

- Core: 7720 / 7520
- Distribution: 5720 / 5520
- Access/edge: 5420 / 4000

## Notes on Recency

November 2025 release, ExtremeConnect 2026 announcements were all tracked at various
points). Never assume this file reflects the current release — always pull the latest
from the KB.
